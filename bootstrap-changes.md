# Bootstrap migration notes

| Removed custom CSS | Bootstrap replacement |
| --- | --- |
| Hand-written page widths and horizontal centering | `container`, `container-fluid`, `row`, `col-*` |
| Flex navigation and its custom spacing | `navbar`, `navbar-expand-md`, `navbar-nav`, `ms-auto`, `gap-md-2` |
| CSS Grid gallery and booking layout | `row`, `row-cols-*`, `col-*`, `g-*` |
| Custom card borders, padding and shadows | `card`, `card-body`, `border-0`, `shadow-sm` |
| Custom table styling | `table`, `table-striped`, `table-hover`, `table-bordered`, `table-responsive` |
| Custom form control and button styling | `form-control`, `form-select`, `form-check`, `btn`, `btn-*` |
| Hand-written spacing and text alignment | `m-*`, `p-*`, `mb-*`, `text-*`, `d-*` utilities |
| Custom fixed-position contact button | `position-fixed`, `bottom-0`, `end-0`, `z-3` |
